# 🎓♾️ CeylonPepper.com | Y2S2 ITP MERN Stack Project

CeylonPepper.com is a full-stack web application developed as part of the **2nd Year 2nd Semester – Information Technology Project (ITP)** module. This project was collaboratively built by a team of five students to support a pepper-based business that collects green and black pepper, processes them into value-added products, and sells them through an online platform.

## 🛒 Project Overview
The system enables customers to purchase a variety of pepper products such as **pepper powder, pepper spray, pepper sauce, and whole pepper** through a user-friendly web interface. It is designed to digitalize and streamline core business operations, from inventory handling to order processing, payments, and delivery coordination.

## ⚙️ Core System Modules
The application is structured into five main functional modules:

- 📦 **Inventory Management** – Product management, stock tracking, and inventory history  
- 💰 **Finance Management** – Customer payments, farmer payments, and financial summaries  
- 🛍️ **Order Management** – Customer orders, order status tracking, and processing  
- 🚚 **Delivery Management** – Delivery assignment, tracking, and fulfillment  
- 🛠️ **Admin Management** – System administration and overall platform control  

## ✨ Key Features
- Role-based dashboards for **Admin, Inventory Manager, Finance Manager, and Delivery Manager**
- User, Farmer, Customer, and Employee management
- Inventory and product management with stock tracking
- Order processing and delivery assignment
- Payment handling for both customers and farmers
- Report generation including:
  - Salary slips  
  - Payment summaries  
  - Inventory history reports  

## 🧑‍🤝‍🧑 Team-Based Development
This project was developed by a **five-member team**, with each member responsible for a specific module. A modular architecture was followed to ensure scalability, maintainability, and smooth integration between system components.

## 🛠️ Technologies Used
**Frontend**
- React.js  

**Backend**
- Node.js  
- Express.js  

**Database**
- MongoDB  
- Mongoose (MongoDB ODM)  

**Additional Libraries / APIs**
- Google Maps API (for delivery tracking)
- Payment Gateway API (for customer payments)

- Develop a real-world business-oriented web application
- Apply full-stack development concepts using the MERN stack
